# Salone Interior Missions Platform

UI-only phase of a mission engagement platform built with Node.js, Express, EJS, Bootstrap 5, and a clean MVC structure.

## What this build includes
- Fully responsive public website pages
- Shared layout and reusable EJS partials
- Warm, ministry-focused visual design with Sierra Leone mission content
- Separate dashboard layout for supporter pages
- Separate admin layout and sidebar for admin pages
- Static sample content, placeholder imagery, and presentational forms only

## Stack
- Node.js
- Express
- EJS
- Bootstrap 5
- MVC file structure

- Admin: `views/layouts/admin.ejs`

## Run locally
1. Install dependencies:
   - `npm install`
2. Start the app:
   - `npm run dev`
3. Open:
   - `http://localhost:3000`

## Notes
- This phase does not include authentication logic.
- This phase does not include database integration.
- Forms and dashboards are static presentation only.
